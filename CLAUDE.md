# CLAUDE.md

## Overview

This repository contains AutoHotkey v2 scripts for automating repetitive gameplay in **Epic Seven** (mobile game). The scripts automate click sequences in the game window using relative screen coordinates so they work regardless of window size/position.

## Running the Scripts

- Install [AutoHotkey v2](https://www.autohotkey.com/) (v2.0+)
- Double-click any `.ahk` file to run it
- **F3** — Toggle the automation loop on/off
- **F9** — Exit the script

No build step or test suite exists.
